# WALL DUEL

Лабиринт с кубиком и стенами на 2–4 игрока: онлайн-комнаты, лобби, боты, локальная игра на одном экране.

Брось кубик и выбери: идти на 1–3 клетки, поставить стену (2 клетки) или, на шестёрке, сломать чужую.
Первым дойди до линии напротив. Бонус-клетки дают стены, дополнительный бросок или заморозку соперника.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # тесты движка и сервера
```

Друзья в одной сети открывают адрес, который сервер печатает при старте. Для игры через интернет разверните сервер на любом
Node-хостинге (нужна поддержка WebSocket) или пробросьте порт, например через `cloudflared tunnel --url http://localhost:3000`.

## Устройство

| Путь | Что внутри |
| --- | --- |
| `public/js/engine.js` | правила игры и ИИ, общий для сервера и браузера |
| `public/js/room.js` | комната: места, лобби, ход партии, боты |
| `server.js` | статика и WebSocket-сервер комнат (сервер авторитетный: ходы проверяются на нём) |
| `public/js/net.js` | транспорты: онлайн (WebSocket) и локальный |
| `public/js/ui.js`, `fx.js` | интерфейс, звук, частицы |
| `tools/gen_assets.py` | генерация графики через Gemini-совместимый API, вырезание фона, сжатие в WebP |
| `docs/design-brief.md` | бриф для редизайна |

## Графика

Картинки лежат в `public/img` (WebP, суммарно около 140 КБ). Перегенерировать:

```bash
GEMINI_BASE_URL=http://127.0.0.1:8317 GEMINI_API_KEY=... python3 tools/gen_assets.py [pawn0 trophy ...]
```

Ключ и адрес читаются только из окружения. В репозиторий они не попадают.
