# WALL DUEL

Тактический лабиринт с кубиками и стенами на 2–4 игрока: онлайн-комнаты, лобби, боты, игра на одном экране.

- **Два кубика с передачей.** В начале хода у вас кубик от предыдущего игрока и свежий бросок. Ходите одним, второй уходит следующему: взять сильный — значит отдать сопернику слабый.
- **Ход:** идти (1–3 → 1 клетка, 4–6 → до 2), поставить стену в 2 клетки или, шестёркой, сломать чужую. Через соседнюю фишку можно перепрыгнуть.
- **Поля 7×7, 9×9 и 11×11:** от быстрой партии до долгой. Бонус-клетки дают стены, ещё ход или заморозку соперника.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # тесты движка и сервера
```

Друзья в одной сети открывают адрес, который сервер печатает при старте. Для игры через интернет разверните сервер на любом
Node-хостинге (нужна поддержка WebSocket) или пробросьте порт, например через `cloudflared tunnel --url http://localhost:3000`.

## Деплой

На сервере игра запускается как systemd-сервис за обратным прокси (Caddy), который даёт HTTPS
и пробрасывает WebSocket: `HOST=127.0.0.1 PORT=3050 node server.js`, в Caddy — `reverse_proxy 127.0.0.1:3050`.

## Боты

Три уровня: «Лёгкие», «Сильные» и «Мастер». Сильный бот оценивает позицию по разнице кратчайших путей до цели
(в ожидаемых ходах), учитывает цену стен в запасе и то, какой кубик отдаёт следующему игроку; из ~130 стен
рассматривает только перерезающие путь лидеров. Мастер вдобавок защищает свой маршрут — избегает позиций,
где одна стена соперника сильно удлиняет его путь. По турнирам на поле 9×9 сильный выигрывает у лёгкого ~76%,
мастер у сильного ~57%. Проверить: `npm run bench [партий] [размер]`.

## Устройство

| Путь | Что внутри |
| --- | --- |
| `public/js/engine.js` | правила игры и ИИ, общий для сервера и браузера |
| `public/js/room.js` | комната: места, лобби, ход партии, боты |
| `server.js` | статика и WebSocket-сервер комнат (сервер авторитетный: ходы проверяются на нём) |
| `public/js/net.js` | транспорты: онлайн (WebSocket) и локальный |
| `public/js/ui.js`, `fx.js` | экраны и ввод, звук |
| `public/js/art.js` | SVG-графика: иконки, фишки, поле, стены |
| `docs/design-brief.md` | бриф для редизайна |

## Дизайн

Интерфейс сделан по макету «Бумага и тушь»: тёплая бумага, контур тушью, плоский цвет только у игроков.
Фишки различаются формой (круг, квадрат, треугольник, ромб), у стен есть знак хозяина. Светлая и тёмная темы
переключаются кнопкой «Тема» или следуют системе. Все картинки это SVG в `public/js/art.js`, внешних файлов нет
(кроме шрифтов Onest и JetBrains Mono с Google Fonts). Бриф на дизайн лежит в `docs/design-brief.md`.
