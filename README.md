# WALL DUEL

Тактический лабиринт на 2–4 игрока: онлайн-комнаты, лобби, боты, игра на одном экране.

- **Ход — три слота:** один шаг, одна стена и одна карта, в любом порядке. Слоты видны и гаснут по мере использования, а когда делать нечего, ход заканчивается сам.
- **Карты — редкие козыри:** новая раз в два хода, рука до 3, соперники её не видят. Рывок, Снос, Поворот, Смещение, Заморозка, Запас.
- **Роли — постоянные свойства:** Бегун делает второй шаг вместо стены, Архитектор ставит две стены, Призрак проходит сквозь стену вместо своей стены, стены Каменщика нерушимы, Сапёр ломает стену рядом, Картёжник играет две карты.
- **Поля 7×7, 9×9, 11×11** и симметричные бонус-клетки. Через соседнюю фишку можно перепрыгнуть.

Дизайн, источники идей и проверка по четырём проверкам ядра — в `docs/game-design.md`.

## Быстрый старт

Нужен Node.js 22.13 или новее (проверить: `node -v`): статистика хранится во встроенном в Node SQLite.
На Node 18–22.12 игра работает с выключенной статистикой: `TELEMETRY=off npm start`.

```bash
git clone https://github.com/renat2006/quoridor_game.git
cd quoridor_game
npm ci
npm start
```

Откройте http://localhost:3000. Сервер печатает и адрес в локальной сети: по нему к вашей комнате
подключаются друзья с телефонов и ноутбуков в том же Wi‑Fi. Игра с ботами и вдвоём на одном экране
(«Играть здесь») работает прямо в браузере, без комнат.

| Команда | Что делает |
| --- | --- |
| `npm start` | сервер игры |
| `npm test` | тесты движка и сервера (поднимают сервер на свободном порту) |
| `npm run bench [партий] [поле]` | турнир ботов: сила уровней и баланс ролей |
| `DATA_DIR=/tmp/wd-demo npm run demo-stats` | демо-данные, чтобы посмотреть дашборд без живых игроков |

Настройки через переменные окружения:

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `PORT` | `3000` | порт HTTP и WebSocket |
| `HOST` | `0.0.0.0` | адрес; за обратным прокси ставьте `127.0.0.1` |
| `DATA_DIR` | `./data` | где лежит база статистики `telemetry.db` |
| `STATS_KEY` | — | ключ входа в дашборд `/stats`; без него дашборд открывается только с самой машины |
| `TELEMETRY` | — | `off` выключает сбор статистики |
| `POSTHOG_KEY`, `POSTHOG_HOST` | —, `https://eu.i.posthog.com` | необязательная запись сессий в PostHog Cloud |

Например: `PORT=8080 npm start`.

### Через Docker

```bash
docker build -t wallduel .
docker run -d --name wallduel -p 3000:3000 --restart unless-stopped \
  -v wallduel-data:/app/data -e STATS_KEY=придумайте-ключ wallduel
```

### Сыграть с друзьями через интернет без сервера

Пробросьте локальный порт туннелем, например
`cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`, и отправьте друзьям выданную ссылку.

## Деплой на свой сервер

Игре нужен один процесс Node.js и прокси с поддержкой WebSocket (путь `/ws`). Готовые конфиги лежат в `deploy/`.

```bash
# на сервере (Ubuntu/Debian), Node.js 18+ и Caddy уже установлены
sudo useradd --system --home /opt/wallduel --shell /usr/sbin/nologin wallduel
sudo git clone https://github.com/renat2006/quoridor_game.git /opt/wallduel
sudo chown -R wallduel:wallduel /opt/wallduel
sudo -u wallduel npm ci --omit=dev --prefix /opt/wallduel

# ключ дашборда /stats (файл читает только root, systemd передаёт его сервису)
echo "STATS_KEY=$(openssl rand -hex 16)" | sudo tee /etc/wallduel.env >/dev/null && sudo chmod 600 /etc/wallduel.env

sudo cp /opt/wallduel/deploy/wallduel.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now wallduel
```

Добавьте в `/etc/caddy/Caddyfile` блок из `deploy/Caddyfile` со своим доменом (A-запись домена должна указывать
на сервер) и выполните `sudo systemctl reload caddy`. Caddy сам выпустит HTTPS-сертификат.
Для nginx нужен `proxy_pass http://127.0.0.1:3050;` с заголовками `Upgrade` и `Connection "upgrade"`.

Обновление:

```bash
sudo -u wallduel git -C /opt/wallduel pull --ff-only && sudo systemctl restart wallduel
```

Комнаты живут в памяти, но переживают перезапуск: по SIGTERM сервер пишет их в `DATA_DIR/rooms.json`,
при старте поднимает обратно (снимок старше 15 минут не берётся), а клиенты сами переподключаются с прежним токеном.
Обрыв связи у игрока не выкидывает его: место в лобби держится 90 секунд, в партии бот подменяет его только через 30
(`GRACE` в `room.js`), а клиент пингует сервер и мгновенно переподключается, когда вкладка снова видна. Для Caddy
в блоке `reverse_proxy` стоит `stream_close_delay 5m`, чтобы перезагрузка конфига не рвала игры. Статистика лежит в
`/var/lib/wallduel/telemetry.db` (SQLite) и переживает перезапуски и обновления. Ключ дашборда: `sudo cat /etc/wallduel.env`.

## Статистика и дашборд

Откройте `/stats` (например, https://wallduo.renat.site/stats) и введите `STATS_KEY`. Что там есть:

- **Главные цифры:** посетители (новые и вернувшиеся), партии и доля доигранных, медианы длины партии,
  раздумий над ходом и отрыва победителя.
- **Активность по дням** и **воронка**: зашёл → начал партию → доиграл → сыграл 2+ партии.
- **Баланс:** доля побед каждой роли рядом с «честной» долей, преимущество первого хода по размеру поля,
  как люди играют против лёгких и сильных ботов.
- **Как играют:** шаги, стены, карты и способности за ход у людей и ботов; какие карты люди играют; на каком ходу бросают.
- **Повтор любой партии** ход за ходом: поле, роли, руки, журнал, перемотка и скорость.
- **Аудитория:** устройства, языки, источники переходов, открытые экраны; **ошибки JavaScript** у игроков.

Как это устроено:

- Комната записывает партию как зерно генератора случайности плюс список действий с отметками времени.
  Этого хватает, чтобы переиграть её движком точь-в-точь. Онлайн-партии записывает сервер, локальные
  («Играть здесь») браузер присылает в конце. Сервер переигрывает каждую запись, а подделанные или битые не сохраняет.
- Браузер раз в несколько секунд отправляет пачку событий: визит, экраны, правила, ошибки. Чтобы не потерять
  последние события при закрытии вкладки, используется `sendBeacon`.
- Игрок опознаётся только случайным id в `localStorage`. Имена, IP и cookies не сохраняются. «Не отслеживать»
  (DNT/GPC) выключает отправку из браузера. В правилах игры об этом есть абзац.
- При изменении правил поднимайте `RULES_VERSION` в `engine.js`: новые записи пометятся новой версией,
  а для старых дашборд предупредит, что повтор может разойтись.

**Запись экрана (по желанию).** Чтобы смотреть не только ходы, но и как люди кликают по интерфейсу, подключите
[PostHog Cloud](https://posthog.com/eu): бесплатно до 5000 записей сессий в месяц, поля ввода маскируются.
Заведите проект в EU-регионе, скопируйте Project API key (`phc_…`) и добавьте строку `POSTHOG_KEY=phc_…`
в `/etc/wallduel.env`, затем `sudo systemctl restart wallduel`. Свой PostHog на этом сервере не поднять:
ему нужно около 32 ГБ памяти.

## Боты и баланс

Три уровня ботов. «Лёгкие» выбирают по одному действию с шумом. «Средние» планируют весь ход лучевым поиском
по цепочкам действий и оценивают позицию по разнице кратчайших путей плюс запас стен и карт. «Сильные» вдобавок
для лучших вариантов своего хода считают лучший ответ соперника (чужую руку бот не видит) и укладываются в 0,4 с.
На 9×9 «Сильные» выигрывают у «Средних» 79%, «Средние» у «Лёгких» — 63%.

Числа правил подобраны турнирами ботов (`npm run bench [партий] [поле]`): в дуэли роли выигрывают 42–61%,
первый ход — 51–54% на всех полях; вчетвером роли держатся в 20–32% при честных 25% (для партий на 3–4 у ролей
свои поправки, `RULES.many`). Таблицы и что пробовали — в `docs/game-design.md`.

| Путь | Что внутри |
| --- | --- |
| `public/js/engine.js` | правила игры и ИИ, общий для сервера и браузера |

| `public/js/track.js` | анонимные события из браузера и отправка локальных партий |
| `public/js/net.js` | транспорты: онлайн (WebSocket) и локальный |
| `public/js/ui.js`, `fx.js` | экраны и ввод, звук |
| `public/js/art.js` | SVG-графика: иконки, фишки, поле, стены |
| `docs/design-brief.md` | бриф для редизайна |
| `deploy/` | systemd-сервис и блок Caddy для своего сервера |
| `Dockerfile` | образ для запуска в Docker |

## Дизайн

Интерфейс сделан по макету «Бумага и тушь»: тёплая бумага, контур тушью, плоский цвет только у игроков.
Фишки различаются формой (круг, квадрат, треугольник, ромб), у стен есть знак хозяина. Светлая и тёмная темы
переключаются кнопкой «Тема» или следуют системе. Все картинки это SVG в `public/js/art.js`, внешних файлов нет
(кроме шрифтов Onest и JetBrains Mono с Google Fonts). Бриф на дизайн лежит в `docs/design-brief.md`.
